📋 Sample Database Schema

students (id, name, age, section, department) courses (id, course_name, credits, instructor) marks (id, student_id, course_id, marks, grade)

1 Introduction to SQL

▼

SQL (Structured Query Language) is the standard language for interacting with relational databases. It lets you create, read, update, and delete data stored in tables.

A relational database stores data in tables (like spreadsheets) with rows and columns. Each table has a name, and each column has a data type (e.g., INTEGER, TEXT, REAL).

SQL is used everywhere — from small apps to massive enterprise systems. Every data scientist, analyst, and engineer needs to know SQL.

Example — View all tables SELECT name FROM sqlite_master WHERE type='table';
🧪 Try it yourself

2 SELECT Statement

▼

The SELECT statement retrieves data from one or more tables. You can select specific columns or use * to select all columns.

Example — Select all students SELECT * FROM students;
Example — Select specific columns SELECT name, department FROM students;
🧪 Try it yourself

3 WHERE Clause

▼

The WHERE clause filters rows based on conditions. You can use operators like =, !=, <, >, LIKE, IN, BETWEEN, AND, OR.

Example — Filter by department SELECT * FROM students WHERE department = 'Computer Science';
Example — Multiple conditions SELECT * FROM students WHERE age > 20 AND section = 'A';
🧪 Try it yourself

4 ORDER BY

▼

ORDER BY sorts query results by one or more columns. Use ASC (default) for ascending or DESC for descending order.

Example — Sort by name SELECT * FROM students ORDER BY name ASC;
Example — Sort by age descending SELECT * FROM students ORDER BY age DESC;
🧪 Try it yourself

5 GROUP BY

▼

GROUP BY groups rows that have the same values in specified columns. It's typically used with aggregate functions like COUNT, SUM, AVG, MAX, MIN.

Example — Count students per department SELECT department, COUNT(*) as student_count FROM students GROUP BY department;
🧪 Try it yourself

6 JOINs

▼

JOIN combines rows from two or more tables based on a related column. Common types: INNER JOIN (only matching rows), LEFT JOIN (all from left + matches), RIGHT JOIN, FULL OUTER JOIN.

Example — Join students with marks SELECT s.name, c.course_name, m.marks, m.grade FROM marks m INNER JOIN students s ON m.student_id = s.id INNER JOIN courses c ON m.course_id = c.id;
🧪 Try it yourself

7 Aggregate Functions

▼

Aggregate functions perform calculations on a set of rows and return a single value: COUNT(), SUM(), AVG(), MAX(), MIN().

Example — Average marks per course SELECT c.course_name, AVG(m.marks) as avg_marks FROM marks m JOIN courses c ON m.course_id = c.id GROUP BY c.course_name;
Example — Highest marks SELECT MAX(marks) as highest, MIN(marks) as lowest FROM marks;
🧪 Try it yourself

8 Subqueries

▼

A subquery is a query nested inside another query. It can appear in SELECT, FROM, or WHERE clauses. Subqueries are powerful for complex filtering and comparisons.

Example — Students with above-average marks SELECT s.name, m.marks FROM marks m JOIN students s ON m.student_id = s.id WHERE m.marks > (SELECT AVG(marks) FROM marks);
🧪 Try it yourself

9 INSERT / UPDATE / DELETE

▼

These statements modify data. INSERT adds new rows, UPDATE changes existing rows, and DELETE removes rows. Always be careful with UPDATE and DELETE — use WHERE to target specific rows!

Example — Insert a student INSERT INTO students (name, age, section, department) VALUES ('Hermione', 22, 'A', 'Computer Science');
Example — Update marks UPDATE marks SET marks = 95 WHERE student_id = 1 AND course_id = 1;
Example — Delete a record DELETE FROM students WHERE name = 'Hermione';
🧪 Try it yourself (changes persist until you reset the database)

10 CREATE TABLE

▼

CREATE TABLE defines a new table with column names and data types. You can add constraints like PRIMARY KEY, NOT NULL, UNIQUE, and FOREIGN KEY.

Example — Create a projects table CREATE TABLE projects ( id INTEGER PRIMARY KEY AUTOINCREMENT, title TEXT NOT NULL, student_id INTEGER, status TEXT DEFAULT 'in-progress', FOREIGN KEY (student_id) REFERENCES students(id) );
